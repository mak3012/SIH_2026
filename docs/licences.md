# Licences

What the platform is built from, under which licence, and what it is used for. Check before
redistributing; CI checks the dependency licences on every push.

## Policy

- **Allowed in code we link or ship:** permissive licences (MIT, BSD, Apache-2.0, ISC, PSF,
  MPL-2.0, BlueOak, 0BSD, Unlicense, CC0), weak copyleft used as a library without
  modification (LGPL: `psycopg`, `asyncua`), fonts under OFL-1.1, and data under CC-BY-4.0
  (`caniuse-lite`, build time only).
- **Denied in code we link or ship:** GPL, AGPL, SSPL, BUSL, Commons Clause, Elastic, non-commercial
  licences. A package licensed "X OR GPL" is fine when X is allowed.
- **Unknown licence:** fails until someone reads the package's licence file and records the
  result in `KNOWN` (or an accepted exception with its reason in `EXCEPTIONS`) in
  `infra/licences.py`.
- **Separate programs** (the container images below) are used unmodified over the network or as
  a server extension; their copyleft does not extend to our code. Offering the stack as a hosted
  service to third parties needs the AGPL and TimescaleDB TSL terms reviewed first.

`make licences` runs the check and rewrites the generated table below; `make sbom` writes a
CycloneDX SBOM of the same packages. CI (`supply-chain` job) fails on a denied or unknown
licence and publishes three SBOMs as build artifacts: the dependencies (CycloneDX, from `infra/licences.py`), the repository (SPDX, syft)
and the `api` and `web` images including their OS packages (CycloneDX, syft).
